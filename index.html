使用说明

LBJ / TDCS 固件与 APP 的基本用法。频率等参数见对应页面，这里只写操作和菜单。

1刷机之前

  1. 原有固件会被覆盖。刷机会抹掉电台原有主固件，原厂固件不会保留。
  2. 先备份校准。打开 校准备份 读取并保存 calibration.dat。校准数据是本机专属，换机恢复可能影响发射指标。
  3. 多固件（可选）。支持多固件的 F4HWN 固件可以把 LBJ 固件写入固件插槽。开机前按住 M 进入选择器；选中的固件将作为主固件启动。写槽本身只动外部 flash，不影响当前主固件。
  4. 固件版和 APP 版二选一。固件版把解码、日志、双守和快捷键都做进固件，功能更全；APP 版（LBJRX / TDCSRX）可装在 LBJ 固件或支持 APP 的 F4HWN 固件上，从 F + 7 启动，进入后自动设置频率。

2操作说明

2.1 快速上手

2.1.1 LBJ

  1. 频率模式输入 LBJ 频率。
  2. 菜单 → 信道 → 模式（Mode）→ LBJ。
  3. 打开静噪或监听，等待解码窗口弹出。窗口里 UP/DOWN 翻历史，MENU 切换实时 / 日志 / 详情，EXIT 关闭。

2.1.2 TDCS

  1. 频率模式输入 TDCS 频率。
  2. 菜单 → 信道 → 模式（Mode）→ TDC。
  3. 等待解码窗口弹出。UP/DOWN 翻历史，6/9 翻页，EXIT 关闭。TDCS 和 KLW 各自保留 8 条历史，翻页不会串到另一种报文。

2.1.3 小技巧

  • 快捷键。菜单 → 按键 → F1Shrt / F1Long / F2Shrt / F2Long / M Long 可以设为 LBJMSG、TDCMSG、KLWMSG 或 MSGBOX。MSGBOX 一个键在 LBJ → TDCS → KLW 三个窗口之间循环，没有记录的窗口自动跳过。
  • 二维码。LBJ 实时报文右上角 km 后面有 * 时，按 * 显示二维码，扫码查看列车位置。只有实时页保留坐标，存盘记录没有。
  • 弱信号。把 SQL 设为 0，或打开监听，让载波能打开静噪。
  • 双守 / 多守。把 A/B 两个信道分别设为联控（普通 FM）、LBJ、TDC 中的两个，RxMode 选 MAIN TX DUAL RX。要同时守 3/4 个信道，选 FULL WATCH，并在 电台 → MON3 / MON4 里各选一个存储信道；S 表行最左边会显示 3/4 徽标，正在接收的那个闪烁。
  • 存信道。最好把设置好的频率和模式存储为信道，方便快速切换。

2.1.4 APP 版

在 管理安装 APP 里装 LBJRX / TDCSRX，电台 F + 7 启动。进入后自动设置频率，和固件版二选一即可。

2.2 设置菜单

只写菜单名称和用途。菜单 → 分类 → 项目；带箭头的分类点一下展开。

2.2.1 LBJ 菜单

二级菜单含义
LBJMSG打开解码窗口，显示最新一条报文；没有报文时不打开。

LBJLOGOFF / ON：把每列车写入车次日志，默认 OFF。
LBJCLRNo / Yes：清空车次日志。
LBJHST打开已存日志列表，可看实时、列表、详情。
LBJPRI-- / A–E：选择测距用的本机位置。
LBJLAT输入纬度 DD MM hh。
LBJLON输入经度 DDD MM hh。
LBJNUMFULL / SIMPLE：车号显示 8 位或 4 位。
语言 LANGCHN / ENG / ENLC：界面语言（仅中文固件）。

二级菜单含义

3中文字体

本页有两个中文固件：LBJRADIO-cn 内嵌常用汉字，不刷字库也能显示，生僻字留空；LBJRADIO-font 不内嵌字模，所有汉字都从下面刷入的字库读取，支持完整 GB2312，但必须先刷字库，否则中文全部空白。

刷入字库后，信道名可以显示中文。本字库与其他汉化 F4HWN 固件不兼容，不要混刷。

刷字体需要 K 头写频线。电台正常开机即可，不要进 DFU；写之前关闭 UV Studio / K5Viewer，写完关机重开。

pip install pyserial
python tools/font_write.py --list
python tools/font_write.py --port COM3 16x16.fon 8x8.fon

COM3 换成实际串口。脚本来自固件仓库的 tools/font_write.py。
